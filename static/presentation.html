System Architecture Domain-Driven Design (DDD) & Clean Architecture

Harness Engineering: Zero Spaghetti, Maximum Stability

Built on a rock-solid separation of UI, business use cases, domain entities, and infrastructure.

🏗️
Clean 4-Layer Architecture
  • 1 Presentation Layer (UI/PWA): HTML5, CSS3, Vanilla JS fetch calls. Fast, lightweight, zero framework bloat.
  • 2 API Gateway (FastAPI): Async Python REST endpoints with strict Pydantic validation & JWT tokens.
  • 3 Harness Layer (Use Cases): Encapsulates all business rules (`RegisterPatientUseCase`, `CallQueueUseCase`, `GenerateBillUseCase`).
  • 4 Domain & Persistence: Pure entities and swappable repositories (SQLite for local, PostgreSQL for cloud).
